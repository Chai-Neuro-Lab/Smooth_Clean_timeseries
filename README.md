# Smooth_Clean_timeseries
This code implements a surface-based denoising pipeline for precision mapping analyses using fMRIPrep outputs.

Starting from preprocessed CIFTI files generated by fMRIPrep, the data are first spatially smoothed with a 2 mm kernel. The pipeline then performs denoising using one example strategy. The data are subsequently detrended, band-pass filtered (0.01–0.1 Hz), nuisance-regressed, and standardized. Nuisance regressors include the six head motion parameters (three translations and three rotations), their temporal derivatives and squared derivatives, and the top five aCompCor components.
